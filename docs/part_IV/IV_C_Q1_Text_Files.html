IV.C Text Files I, Q1: Reading with next()

Learning Objectives

  • Trace next() through a text file.
  • Predict what head(filepath, n) prints.

Background

A text file has a reading position. Each next() reads one line and moves forward; a blank line counts too. This activity shows the reads and output step by step, to help you write head(filepath, n).

Instructions

  1. Predict. Keep the example file, program and n = 3. Write the lines you expect to be printed.
  2. Follow the reads. Click Open file / restart, then Execute next step. Watch the next unread line, the operation and the printed output. Use Run to end to finish.
  3. Compare. Try n = 0, n larger than the file, and the other programs. Reopen after changing an input. Explain what happens to blank lines and at the end of the file.
