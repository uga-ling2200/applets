IV.C Text Files I, Q1: Reading with next()

Learning Objectives

  • Trace next() and a for loop through the same open file.
  • Predict the output of head(filepath, n), including blank lines and end of file.

Background

The notebook asks for head(filepath, n), which prints the first n lines of a text file. Each next(in_file) returns one line and advances the file iterator. A loop continues from the current position.

Instructions

  1. Predict the output, then open the file.
  2. Step through the code and track the highlighted line and output.
  3. Compare the three programs. Try n = 0, n equal to the file length, and n greater than the length.

    Reflection & Discussion Guide
    1. Why does the second next() return a different line?
