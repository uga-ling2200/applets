V.A Regex I, Q2: Filtering strings

Learning Objectives

  • Trace how a search result controls a branch.
  • Plan a loop that returns complete matching input strings.
  • Test no matches, repeated entries and empty input.

Background

The notebook asks for re_hits(pattern, candidates): a function that returns the complete strings containing a match. A match can occur anywhere. re.search() returns a Match object on success, or None on failure. Python can test either result directly in an if.

Instructions

  1. Complete the five practice pages below. With a partner, alternate proposing and checking an explanation. Alone, write your reasoning first.
  2. Use the lab to follow one candidate at a time. Compare the search result with the complete string added.
  3. Write your own function in your course notebook, then record your explanation. Practice scores are local and are not submitted.

    Why can an empty matching substring still succeed?

    The pattern r"a*" can match zero characters. Python still returns a Match object, which is truthy. Test the object, not whether its matched text is nonempty. The advanced case is optional; focus first on the basic filtering plan.
