V.B Regex II, Q1: Greedy and lazy quantifiers

Learning Objectives

  • Predict the matched text for greedy and lazy quantifiers.
  • Choose a quantifier based on an extraction goal.
  • Explain why the whole pattern must succeed, even with a lazy quantifier.

Background

A quantifier controls how often part of a pattern can repeat. * allows zero or more repetitions and is greedy: it tries more repetitions first. *? allows the same repetition counts and is lazy: it tries fewer repetitions first. Both must allow the entire pattern to match.

In these single-line examples, . matches any character, including an angle bracket. The literal characters < and > must also match. r"..." is Python raw-string notation. re.search() finds the first successful match; .group() returns its complete text. If no match exists, re.search() returns None.
